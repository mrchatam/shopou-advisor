# Contributing

This repository is the public issue tracker for the Shopou Advisor connector. It
does not contain the server code, and pull requests that change the service
cannot be accepted here.

You can still help a lot:

## Report a problem

- Search the existing issues first — someone may have hit the same thing.
- Open one issue per problem, using the closest template.
- Include the date and time with the timezone, what you asked, and which answer
  or tool was involved.

Prices move and every answer states when it was read, so re-ask before reporting
a price that looks wrong. "Prices unavailable" means the retailer could not be
read, not that nothing fits the budget.

## Ask a question

Open-ended questions belong in
[Q&A](https://github.com/mrchatam/shopou-advisor/discussions/new?category=q-a),
and suggestions in
[Ideas](https://github.com/mrchatam/shopou-advisor/discussions/new?category=ideas).
The issue forms are for things that need tracking to a resolution.

## Protect your account

Never paste access tokens, refresh tokens, passwords, API keys or personal
information into an issue or a discussion. A report never needs them. Cover
tokens in screenshots.

## Language

English and Persian are both welcome. Every issue form is bilingual, so write in
whichever you prefer; answers come in the language you used.

## What to expect

This is a small, privately operated service. Reports are read on a best-effort
basis. A wrong price or a missing listing may be corrected without a reply on the
issue; a connector failure will get an answer when there is one.

## Conduct

Everyone here is held to the [code of conduct](CODE_OF_CONDUCT.md).

## مشارکت (فارسی)

این مخزن فقط برای گزارش مشکل و پرسش دربارهٔ کانکتور دستیار خرید است. کد سرور در آن
نیست و پول‌ریکوئستی که سرویس را تغییر دهد اینجا پذیرفته نمی‌شود.

- اول ایشوهای موجود را بگردید.
- پرسش‌های باز و پیشنهادها در بخش گفت‌وگو جای بهتری دارند: «پرسش و پاسخ» و «ایده‌ها».
- برای هر مشکل یک ایشو باز کنید و نزدیک‌ترین فرم را انتخاب کنید.
- تاریخ و ساعت با منطقهٔ زمانی، چیزی که پرسیده‌اید و ابزاری که پاسخ داده را بنویسید.
- قیمت‌ها عوض می‌شوند؛ پیش از گزارش قیمت، یک بار دیگر بپرسید.
- توکن، رمز، کلید API یا اطلاعات شخصی را هرگز در ایشو یا گفت‌وگو نگذارید.
- فارسی و انگلیسی هر دو پذیرفته است؛ فرم‌ها دوزبانه‌اند.

این سرویس کوچک و خصوصی است و گزارش‌ها در حد توان خوانده می‌شوند.
