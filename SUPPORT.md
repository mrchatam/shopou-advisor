# Support

Pick the route that matches the problem, so it reaches the right place.

| What you have | Where it goes |
| --- | --- |
| The connector will not connect, sign-in fails, a tool errors, or an answer is clearly wrong | [Open a connector problem](https://github.com/mrchatam/shopou-advisor/issues/new?template=bug.yml) |
| A price, stock state, seller or specification does not match the listing | [Report the listing](https://github.com/mrchatam/shopou-advisor/issues/new?template=price.yml) |
| A question, an idea, or "can it do…?" | [Discussions](https://github.com/mrchatam/shopou-advisor/discussions) — [Q&A](https://github.com/mrchatam/shopou-advisor/discussions/new?category=q-a) or [Ideas](https://github.com/mrchatam/shopou-advisor/discussions/new?category=ideas) |
| An order, payment, delivery, return, warranty or Digikala account problem | Digikala support — this service never places an order |
| A security vulnerability | [Report it privately](SECURITY.md), never in a public issue |

Before writing, check the two pages that answer most questions:

- [Support page, English](https://advisor.shopou.ir/support) — what to check first.
- [صفحهٔ پشتیبانی، فارسی](https://advisor.shopou.ir/fa/support).

## پشتیبانی (فارسی)

| چه چیزی دارید | کجا بروید |
| --- | --- |
| کانکتور وصل نمی‌شود، ورود گیر می‌کند، ابزاری خطا می‌دهد یا پاسخ روشن خطا بوده | [گزارش مشکل کانکتور](https://github.com/mrchatam/shopou-advisor/issues/new?template=bug.yml) |
| قیمت، موجودی، فروشنده یا مشخصات با صفحهٔ کالا نمی‌خواند | [گزارش اطلاعات کالا](https://github.com/mrchatam/shopou-advisor/issues/new?template=price.yml) |
| پرسش، ایده یا «می‌تواند این کار را بکند؟» | [گفت‌وگو](https://github.com/mrchatam/shopou-advisor/discussions) — [پرسش و پاسخ](https://github.com/mrchatam/shopou-advisor/discussions/new?category=q-a) یا [ایده‌ها](https://github.com/mrchatam/shopou-advisor/discussions/new?category=ideas) |
| سفارش، پرداخت، ارسال، مرجوعی، گارانتی یا حساب دیجی‌کالا | پشتیبانی دیجی‌کالا — این سرویس هیچ‌وقت سفارشی ثبت نمی‌کند |
| آسیب‌پذیری امنیتی | [خصوصی گزارش کنید](SECURITY.md)، هرگز در ایشوی عمومی |

پیش از نوشتن، این دو صفحه بیشتر پرسش‌ها را جواب می‌دهند:
[صفحهٔ پشتیبانی فارسی](https://advisor.shopou.ir/fa/support) و
[English support](https://advisor.shopou.ir/support).
